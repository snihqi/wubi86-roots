# 五笔字根练习 · 86 版

五笔 86 版字根练习，单文件网页，打开即用。按字根所在的字母键作答，答错不换题；点键盘上任意键位可查该键的全部字根与简码。

**在线版：** <https://snihqi.github.io/wubi86-roots/> ｜ 也可下载 `index.html` 本地双击打开。
姊妹项目：[五笔打字练习](https://snihqi.github.io/wubi86-typing/)。

## 说明

- 答对得 1 分起，随连击档位递增；答错不得分、不扣分，连击归零
- `Z` 是万能键，不判题
- 段位 50 级，点右上角段位名可看阶梯
- 每日四档任务，`06:00` 清零，达标后点「领取」加分
- 界面固定深色；进度存浏览器本地，可导出导入

## 数据来源与许可

字形、字根名、口诀、配色取自 [sdcb/wubi86-viewer](https://github.com/sdcb/wubi86-viewer)（AGPL-3.0）；本项目分发的只是由其字根字体转出的矢量轮廓，不含字体文件，该字体上游未注明出处。五笔 86 方案（王永民，1983）属公有领域。本项目许可见 [LICENSE](LICENSE)（AGPL-3.0）。

源码即 `index.html`，无构建、无压缩；发布时替换该文件，**文件名不要改**（改了进度会读不到）。
