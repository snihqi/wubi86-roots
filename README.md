# 五笔字根练习 · 86 版

一个单文件的五笔字根记忆练习工具。打开网页就能练，不用安装、不用登录、不联网。

**在线版：** <https://snihqi.github.io/wubi86-roots/>

> 148 KB（gzip 后 57 KB），零外部请求（无 CDN、无字体、无统计脚本、无账号）。也可以把 `index.html` 存到本地双击打开，完全离线。

---

## 这是什么

把 86 版五笔的 **303 个字根（含变体）** 和 **25 个一级简码**做成 328 道题，用一套按熟练度调度的队列决定下一题出哪个——打得越熟的，隔得越久；打错的，留在原地重来。

- **不是背口诀**，是练「看到字形 → 手指反应出键位」的条件反射
- 每张卡第一次出现时会给答案：正确键位、区名、口诀，跟着打一遍即可
- 答错不换题，题目留在原地，打到对为止

## 怎么用

按下字根所在的字母键就行。Z 是万能键，不参与练习，按了不判对错也不扣分。

**记住三件事：**

1. 第一次遇到某张卡时，界面会给「正确键位」和口诀，照着打
2. 打错会扣分，扣的是「当前每次得分 × 5」——连击越高，失误越疼
3. 分数只影响段位，**不影响出题顺序**；进度是按熟练度算的

## 几个能省事的功能

- **键盘速查**：点键盘上任意一个键，弹出这一键的全部字根和它的简码。练到某个键老是错，直接对一遍。
- **五区分色**：横区红、竖区橙、撇区绿、点区蓝、折区紫，和口诀表的区序一致。打字区那个字始终是黑色——那是要盯着比对的对象，不跟着变色。
- **50 级段位**：从 Lv1「不堪一击」到 Lv50「返璞归真」。点右上角段位名可以看完整阶梯。
- **使用说明**：右上角「使用说明」按钮，或按 `?`。第一次打开时会自动展开一次。

## 关于进度

进度存在浏览器本地（localStorage），**不上传任何数据**。

- 同一个浏览器、同一个网址打开，自动接着上次
- **换浏览器、换电脑、清过缓存，进度就没了** → 用右下角「导出进度」存一个 `.json`，到新设备「导入进度」
- ⚠️ **改了网址或文件名，进度会读不到**（浏览器按网址隔离存储）。要改名就先导出

## 出题调度

用「位置队列」式的间隔重复：答对后按熟练度把卡插回队列靠前的位置，答错留在原地重来。

这种思路在 SRS 类工具里很常见，本质是**用队列位置代替时间间隔**——不需要时钟，也就不会因为关掉页面而错乱。

本项目按 328 题的规模调整了插回位置表。**实测：前 1000 题只会碰到约 120 张卡**（占 37%），练得最勤的那张出场 9 次——这是间隔重复的固有形态，不是调度坏了。到第 2828 题时 328 张全部出过一遍，之后每张的出现次数稳定在 11～13 次，非常均匀。

## 自己改

整个工具就是一个 `index.html`，纯原生 JS，没有依赖、没有打包。

- 改完直接刷新浏览器即可，没有构建步骤
- 要发布就在仓库里替换 `index.html`（**文件名不要变**，变了所有人的进度会丢）
- 所有数据都在文件里那几个 `const` 里：`GLYPHS`（字根路径）、`YIJIAN`（一级简码）、`RANKS`（等级阶梯）。改题量、改段位只动这里，渲染逻辑不用碰

## 已知特性（不是 bug）

- **前 1000 题只覆盖约 120 张卡**：间隔重复的固有形态，不是调度坏了
- **失误对分数的打击远超直觉**：扣一次等于白打 5 次，连击还归零。用 5000 题做模拟，全程不出错约到 Lv30；正确率 99% 只到 Lv14，95% 停在 Lv10。这套计分奖励的是「不出错」，不是「练得多」
- **分数下降会让等级掉回去**：没做「只升不降」保护
- **窗口宽度 ≤1180px 会变成上下排布**，需要滚动
- **存档版本升级会让旧进度归零**：字根表换过，旧的编号对不上新卡，硬迁移会把熟练度错配到别的字根上，所以宁可不迁移
