# 五笔字根练习 · 86 版

一个单文件的五笔字根记忆练习工具。打开网页就能练，不用安装、不用联网（除了第一次打开）。

**在线版：** https://snihqi.github.io/wubi86-roots/

## 这是什么

把 86 版五笔的 **211 个字根（含变体）+ 25 个一级简码** 做成刷题练习，用一套「间隔重复」的调度算法决定下一题出哪个——打得越熟的，隔得越久；打错的，留在原地重来。

- **不是背口诀**，是练「看到字形 → 手指反应出键位」的条件反射
- 每张卡第一次出现时会给答案，跟着打一遍即可
- 答错不换题，题目留在原地，直到打对为止

## 怎么用

按下字根所在的字母键就行。键盘上 Z 是万能键，不参与练习，按了不判对错也不扣分。

**记住三件事：**

1. 第一次遇到某张卡时，界面会显示「正确键位」和助记词，照着打
2. 打错会扣分，扣的是「当前每次得分 × 5」，所以连击越高，失误越疼
3. 分数只影响段位徽章，不影响出题顺序——**进度是按熟练度算的，不是按分数**

## 关于进度

进度存在浏览器本地（localStorage），**不上传任何数据**。

- 同一个浏览器、同一个网址打开，进度自动接着上次
- **换个浏览器、换台电脑、清过缓存，进度就没了** → 用右下角的「导出进度」存一个小 `.json` 文件，到新设备「导入进度」
- ⚠️ **改了网址或文件名，进度会读不到**（浏览器按网址隔离存储）。要改名就先把进度导出

## 算法出处

调度算法参考 [虎码字根练习](https://tiger-code.com/practice/base)：答对后按固定位置插回队列（第 2、4、8、12、20、30、60、100 位），第 9 次起进队尾；答错清零、原地重来。本质是用「队列位置」代替「时间间隔」的间隔重复。

段位阶梯的积分取自《热血传奇》，等级名取自《英雄坛说》，纯属致敬。

## 字形来源

字根字形（PNG）取自「极速字根练习软件 v0.1（86 版）」，以 base64 内嵌在 HTML 里，所以整个工具只有一个文件、不依赖任何字体。

86 版字根体系属于王永民先生的设计。**如果你要二次分发，请自行确认字形图片的使用是否合适**——代码部分随便用，字形部分是别人软件里提取的。

## 自己改

整个工具就是一个 `index.html`，没有构建步骤、没有依赖。

改完直接刷新浏览器即可。要发布就在仓库里替换 `index.html`（**文件名不要变**，变了用户的进度会丢）。

## 已知特性（不是 bug）

- **前 1000 题会集中在少数卡上**：这是间隔重复的固有形态，前几张被反复巩固，后面的卡排队。跑到 4000 题时 236 张全部覆盖且分布均匀
- **失误率高于 10% 时分数涨不动**（扣一次 = 白打 5 次答对）
- **分数下降会让等级掉回去**，没做「只升不降」保护
- 窗口宽度 ≤1180px 会变成上下排布的单列布局
